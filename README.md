# 🌤️ WeatherNow

A responsive weather application built using **HTML, CSS, and JavaScript** that displays real-time weather information for cities around the world.

## ✨ Features

- 🌍 Search weather by city name
- 📍 Get weather using current location
- 🌡️ Real-time temperature
- 💧 Humidity information
- 💨 Wind speed
- 👁️ Visibility
- 🌡️ Feels-like temperature
- 📅 5-day weather forecast
- ☀️ Weather condition icons
- 🌙 Dark / Light mode
- 📱 Responsive design
- ⚠️ Error handling for invalid cities

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Geolocation API
- LocalStorage
